# iKen Movie Web App

A modern web platform for browsing and watching movie trailers, featuring upcoming and popular films with detailed information.

**Live Demo**: [https://kiptoo-097.github.io/iken/](https://kiptoo-097.github.io/iken/)  
**Repository**: [https://github.com/kiptoo-097/iken](https://github.com/kiptoo-097/iken)


## Features

🎬 **Movie Discovery**
- Browse popular, upcoming, and top-rated movies
- Search functionality with filters
- Detailed movie pages with trailers

📱 **Responsive Design**
- Mobile-first approach
- Adaptive layouts for all devices
- Touch-friendly navigation

🌟 **User Experience**
- Watch trailers in high quality
- View cast information and crew details
- Read movie synopses and reviews
- See release dates and ratings

🔍 **Advanced Features**
- Personalized recommendations
- Watchlist functionality
- Dark/light mode toggle

## Technologies Used

### Frontend
- React.js (Create React App)
- Redux for state management
- Axios for API requests
- Styled Components
- React Router

### Backend (if applicable)
- Node.js/Express (optional)
- Firebase (optional for authentication)

### API
- The Movie Database (TMDb) API

### Deployment
- GitHub Pages
- Netlify (optional)
